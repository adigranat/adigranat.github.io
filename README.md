## פתיחה מקומית
אפשר לפתוח את `index.html` ישירות, או להפעיל Live Server ב־VS Code.

## העלאה ל־GitHub Pages
העלו את כל תכולת התיקייה לשורש המאגר. ב־Settings → Pages בחרו Branch: `main`, Folder: `/ (root)`.

## הערות
- התמונות הכבדות הומרו ל־WebP לצורך טעינה מהירה יותר.
- דפי טיוטה ישנים שאינם חלק מהניווט הוסרו מגרסת הפרסום.
- הטופס בדף יצירת הקשר נשען על מנגנון הקיים באתר; יש לבדוק שליחה בפועל לאחר העלאה לשרת.
