# אתר ד״ר עדי גרנט — Signature V6

גרסה זו משלבת עקרונות עיצוב שנבחרו מתוך שני אתרי השראה:
- ניקיון, צילום אישי, מבנה שירותים ברור ושפה אנושית.
- זהות מקצועית חזקה, הפרדה בין מטופלים להכשרות ותוכן מקצועי עשיר.

## הקבצים
- index.html — התוכן והמבנה
- style.css — העיצוב
- script.js — תפריט נייד ועדכון השנה
- EDITING-GUIDE-HE.md — מדריך עריכה
- .nojekyll — התאמה ל-GitHub Pages

## פתיחה
פתחו את index.html או הפעילו Live Server ב-VS Code.

## הערה לגבי התמונה
התמונה נטענת כרגע משרת Wix. כדי שהאתר יהיה עצמאי, מומלץ לשמור את התמונה בתיקיית assets ולשנות את src בקובץ index.html.
