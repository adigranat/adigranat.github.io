# אתר ד״ר עדי גרנט — V106

גרסה סופית, נקייה ועצמאית לפרסום של האתר הרב־עמודי של ד״ר עדי גרנט.
החבילה כוללת את כל קבצי האתר ואת כל קבצי המדיה הנדרשים, ולכן ניתן להעלות אותה ל־GitHub Pages גם לאחר מחיקת קבצי גרסה קודמת.

## עדכון V106
- בעמוד „אודותיי” נוספה התמונה שסופקה כפי שהיא, ללא שינוי בתמונה או בכיתוב המובנה בה.
- לא נוסף כיתוב HTML נפרד מעל התמונה, כדי למנוע כפילות.
- התמונה מותאמת רספונסיבית לדסקטופ ולמובייל.

## אחידות עיצובית שבוצעה ב־V104
- ארבעת דפי העומק שמקושרים מהפוטר קיבלו מסגרות תוכן באותו עיצוב של המסגרות המאושרות בדפי התפריט הראשי.
- המסגור הוחל על מקטעי התוכן המרכזיים ועל אזור השאלות הנפוצות בדפים: טראומה ואובדן, מחלה/כאב ושיקום, ילדים והדרכת הורים, ואבחון נוירופסיכולוגי.
- המלל עצמו לא שונה.
- נשמרו רקעי המקטעים, ה־CTA, מבנה ה־SEO/GEO והתאמת המובייל.

## ניקוי שבוצע ב־V103
- כל קבצי `assets` שולבו בתוך החבילה; אין תלות בגרסה קודמת.
- הוסר קובץ האזהרה הישן `IMPORTANT-ASSETS.txt`, שכבר אינו רלוונטי.
- `style.css` נוקה באופן שמרני: הוסרו הערות גרסה ישנות, הצהרות זהות כפולות וכללי CSS זהים שחזרו ללא צורך.
- נשמר סדר ה־cascade וכל override שמשפיע על העיצוב, כדי שלא לשנות את המראה שאושר.
- README ו־`VERSION.txt` עודכנו לגרסה הנוכחית.

## העלאה ל־GitHub Pages
1. פתחו את המאגר `adigranat.github.io`.
2. ניתן למחוק את קבצי האתר הישנים.
3. העלו את **כל התוכן שבתיקיית V104**, כולל תיקיית `assets` והקובץ `.nojekyll`.
4. ודאו שב־Settings → Pages מוגדרים Branch: `main` ו־Folder: `/ (root)`.
5. לאחר הפרסום בדקו את דף הבית, עמוד „אני מאמין”, עמוד טראומה ועמוד יצירת קשר גם במחשב וגם במובייל.
